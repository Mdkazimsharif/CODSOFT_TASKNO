# Python Calculator

A beginner-friendly command-line calculator written in Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Repeats calculations until you choose to exit
- Handles non-numeric input and division by zero

## Requirements

- Python 3

## How to run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python calculator.py
   ```

   On some systems, you may need to use:

   ```bash
   python3 calculator.py
   ```

## How to use

1. Enter the first number.
2. Enter the second number.
3. Select an operation from 1 to 4.
4. Follow the prompt to calculate again or exit.

## Concepts practiced

- `input()` and `print()`
- Variables and numeric conversion with `float()`
- `if`, `elif`, and `else`
- `while` loops
- Error handling with `try` and `except`
- Functions
